# BTS Group website

เว็บไซต์ BTS Group ภาษาไทยและอังกฤษ ใช้ฟอนต์ OzoneX และ Mulish ของ BTS พร้อมข้อมูลและโลโก้ BTS พร้อมรายละเอียดเส้นรางและจุดเชื่อมต่อในสีขาว น้ำเงิน และแดง

## เปิดเว็บไซต์

```sh
npm start
```

เปิด http://127.0.0.1:4173/ โดยใช้ Node.js 18 ขึ้นไป ไม่ต้องติดตั้ง dependencies สำหรับการรันเว็บไซต์

GitHub Pages: https://dearwarisara.github.io/bts-test-website/

## หน้าเว็บและเมนู

- ทั้ง 1,002 หน้าใช้หัวเว็บ เมนู และท้ายเว็บร่วมกัน
- เมนูใช้ชื่อ ลำดับ และเมนูย่อยจากโครงสร้าง BTS ใน site-catalog.json
- เมนู ผลค้นหา และลิงก์เนื้อหาที่มีหน้าในเว็บเรา เชื่อมไปยังเส้นทางภายใน
- ภาษา TH/EN เชื่อมหน้าคู่ภาษาในเว็บเรา
- หน้าแรกแสดงข่าวล่าสุด ข้อมูลสำคัญทางการเงิน เอกสารเผยแพร่ ธุรกิจ และความยั่งยืนของ BTS
- เนื้อหา ตาราง ข่าว และเอกสารของหน้าภายในคงข้อมูลต้นฉบับไว้
- ไฟล์ดาวน์โหลด วิดีโอ และสื่อที่โฮสต์โดย BTS ใช้แหล่งต้นฉบับ

## สร้างและตรวจเว็บไซต์

เครื่องมือสร้างใช้ Python และ Beautiful Soup โดยเว็บไซต์ที่พร้อมรันอยู่ใน dist/ แล้ว

```sh
npm run build:site
npm run audit:site
npm test
npm run build:pages
```

unify_bts_site.py สร้างหน้าแรกจากข้อมูล BTS และใช้ shell / ฟอนต์ / ธีมเดียวกันกับทุกหน้า พร้อมปรับลิงก์ต้นฉบับให้ตรงกับ route ภายใน

audit_bts_site.py ตรวจทุกหน้า ทั้งโครงสร้างเมนู ลิงก์ภายใน และเนื้อหาหน้าภายในเทียบกับ Git HEAD แล้วเขียนผลใน site-unification-report.json

## โครงสร้างสำคัญ

- dist/planb-style.css: เลย์เอาต์ส่วนกลาง พื้นน้ำเงินไล่เฉด มุมโค้ง และรายละเอียดเส้นรางสี BTS
- dist/planb-motion.js: แท็บรายงาน; ซีนเปิดเป็นวิดีโอเต็มพื้นที่ เลื่อนตามหน้าปกติ มีข้อความ Borderless Transform Solutions แบบเดิม และไม่มีซูมออก
- apply_planb_style.py: ใช้สไตล์ปัจจุบันหลังสร้างข้อมูลและเมนู BTS
- dist/metro.css และ dist/metro.js: โครงสร้างและการทำงานร่วมกันของเว็บไซต์
- dist/bts-brand.css: ฟอนต์ BTS สี และรายละเอียดเอกลักษณ์
- dist/bts-inner.css: หัวเว็บร่วม หน้าภายใน ตาราง เอกสาร และ responsive layout
- dist/content.js: ค้นหาในหน้า คลังเอกสาร และแท็บของเนื้อหา
- dist/site-catalog.json: ข้อมูลหน้า route และโครงสร้างเมนู BTS
- navigation-tree.json: โครงสร้างเมนูต้นฉบับ
- build_metro_home.py: ข้อมูลและโครงสร้างหน้าแรกก่อนใช้ shared shell

เมื่อสร้างข้อมูลจาก build_pages.py ใหม่ ให้รัน npm run build:site ต่อเพื่อใช้ธีมร่วมเวอร์ชันปัจจุบัน

## เผยแพร่

Push main แล้ว GitHub Actions จะตรวจและจัดแพ็กด้วย build-pages.mjs ก่อนเผยแพร่ GitHub Pages อัตโนมัติ โดยปรับเส้นทางไฟล์ให้รองรับ /bts-test-website/

ข้อมูลและสื่ออ้างอิง https://www.btsgroup.co.th/th/home ส่วนแนวทางการจัดวางปัจจุบันอ้างอิง https://investor.planbmedia.co.th/en/home โดยคงฟอนต์ โลโก้ ชื่อเมนู หัวข้อ และข้อมูลของ BTS

สีหลักอิง stylesheet BTS ต้นฉบับ: น้ำเงิน #02559b, น้ำเงินเข้ม #024577, ตัวอักษร #23324e และพื้นอ่อน #eaeff7

## การตรวจหน้าตาและลิงก์

- หน้าแรกใช้การ์ด MOVE / MIX / MATCH ที่เปิดหน้าธุรกิจแยกกัน
- รายการความยั่งยืนเป็นลิงก์ภายในจริง; hover/focus เปลี่ยนภาพตัวอย่างโดยไม่ขวางการเปิดหน้า
- dist/bts-quality.css ควบคุมขนาดไอคอน การตัดบรรทัด กล่องที่ขยายตามเนื้อหา และระยะขอบของเนื้อหาที่นำเข้า ใช้กับทั้ง 1,002 หน้า
- tests/home-links.test.mjs ป้องกันการ์ดธุรกิจลิงก์ซ้ำและรายการความยั่งยืนที่กดไม่ได้
- visual-review-report.json บันทึกการตรวจการล้นและไอคอนในหน้าตัวแทนครบ 15 กลุ่มเลย์เอาต์ ไทย/อังกฤษ ที่ขนาด desktop และ mobile พร้อมผลทดสอบการคลิกลิงก์

## ตรวจการ์ดข้อมูลที่เกี่ยวข้อง

- repair_cards.py ใช้กล่องเนื้อหาที่มี padding จริงกับการ์ดทั้ง 2,997 ใบ รวมการ์ดในบทความที่สร้างจาก catalogue
- card_content.py สรุปคำบรรยายที่จบประโยค หรือแสดง … อย่างชัดเจนเมื่อเป็นข้อความตัดตอน; ไม่ตัดกลางคำโดยไม่มีเครื่องหมาย
- การ์ดที่โหลดจากผลค้นหาและคลังเอกสารใช้โครงสร้างเดียวกันผ่าน resultCards ใน content.js / navigation.js
- full-layout-review-report.json บันทึกการตรวจ DOM ของทุก 1,002 หน้า ที่ 1440×900 และ 390×844 ครอบคลุมความกว้าง/ความสูงข้อความ padding การ์ด ช่องว่างเหนือภาพ และขนาดไอคอน พร้อมการตรวจคลังเอกสารแบบ dynamic แยกอีก 12 หน้าต่อขนาดจอ การตรวจนี้เป็นการวัดเลย์เอาต์ ไม่ใช่การดูภาพทุกส่วนด้วยตา
- แก้เมนูย่อยชื่อยาว ตำแหน่งกรรมการที่ถูกตัดบรรทัด และ URL ยาวในหน้า MATCH ที่พบระหว่างตรวจครบทุกหน้า

## Our History

หน้าไทยและอังกฤษใช้ไทม์ไลน์กว้างเต็มพื้นที่ มีเส้นกลาง จุดสถานี และเนื้อหาสลับซ้าย–ขวา แทนฉาก 3D เดิม บนมือถือปรับเป็นเส้นด้านซ้ายและเนื้อหาคอลัมน์เดียว

- redesign_history.py คงข้อความเหตุการณ์และปีเดิมทั้ง 21 ช่วงต่อภาษา และทำงานต่อจากการสร้างธีมร่วม
- dist/history-timeline.css / dist/history-timeline.js: ภาพ cover พร้อมไล่สีมืด ชื่อหน้าสีขาว และเส้นแสดงความคืบหน้าขณะเลื่อน โดยไม่มีช่วงปี จำนวนเหตุการณ์ หรือแถบเมนูรอง
- apply_inner_covers.py / dist/bts-covers.css: cover ภาพถ่ายเต็มพื้นที่สำหรับหน้าภายในทุกหน้า พร้อมไล่สีมืดและชื่อหน้าสีขาว ใช้ภาพจาก BTS ตามหัวข้อ MOVE / MIX / MATCH การเงิน ธรรมาภิบาล สิ่งแวดล้อม สังคม และหมวดเนื้อหาอื่น ส่วนข่าวใช้ภาพจากบทความเมื่อมีภาพแนวนอนที่เหมาะสม ภาพ delivery เก็บใน dist/assets/covers/ และแหล่งที่มาบันทึกใน inner-cover-report.json ตรวจทั้งชุดด้วย npm run audit:covers
- apply_video_covers.py: หน้าแรกใช้วิดีโอเสือจาก /storage/bilboard/video-banner.mp4 ของ BTS ต้นฉบับ ส่วน cover หน้าหลักนักลงทุนสัมพันธ์ใช้ /storage/investor-relations/home/video-banner.mp4 พร้อมปุ่มเล่น/หยุดและรองรับ reduced motion โดยไม่มีเครื่องเล่นซ้ำในเนื้อหาด้านล่าง
- การตรวจเนื้อหาประวัติเปรียบเทียบข้อความเหตุการณ์และปีโดยตรง โดยไม่รวมข้อความตกแต่งของฉากเดิม

## ภาพประกอบประวัติและรถบนราง

- ภาพประกอบแต่ละปี 21 ภาพ เจนด้วย built-in image_gen ในชุดสถาปัตยกรรมจำลอง โทนขาว น้ำเงิน แดง เป็นภาพคอนเซปต์ที่ระบุ AI ในคำกำกับ
- history-image-prompts.json เก็บพรอมป์ต์ที่ใช้จริง ชื่อไฟล์ และขนาดภาพ ต้นฉบับ PNG เก็บใน output/imagegen/history/ ภายใน workspace; หน้าเว็บใช้ WebP ที่ความละเอียดเดิมใน dist/assets/history-generated/ รวมประมาณ 6.6 MB และโหลดแบบ lazy
- เส้นกลางเป็นรางคู่พร้อมขบวนรถ BTS มุมมองจากด้านบนแบบ SVG จำนวน 3 ตู้ ตัวรถเคลื่อนตามความคืบหน้าการเลื่อนหน้า
- redesign_ir_home.py / dist/ir-home.css: หน้าหลักนักลงทุนสัมพันธ์ใช้กริดกราฟและเอกสารที่อ่านง่าย ไอคอนขนาดเล็ก การ์ดรายงานเท่ากัน และรายการงบการเงินแบบ details ที่เปิดด้วยคีย์บอร์ดได้ แทน Bootstrap modal ที่แสดงผิดตำแหน่ง โดยคงข้อมูลและลิงก์เอกสารเดิม
- IR modern presentation: พื้นข้อมูลการเงินสีน้ำเงินเข้ม และการ์ดรายงานประจำปีที่ใช้ภาพแนวคิดรถไฟฟ้าและเมืองยามเย็น สร้างด้วย built-in image_gen; พรอมป์ต์และตำแหน่งไฟล์เก็บใน ir-image-prompt.json ภาพเว็บ dist/assets/ir/connected-city-v1.webp ขนาดประมาณ 249 KB และต้นฉบับ output/imagegen/ir/connected-city-v1.png
